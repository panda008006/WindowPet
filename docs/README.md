# Window Pet 文档目录

旧的上游发布宣传页和发布候选说明已经从交接包中移除，避免把 Window Pet 误认为其他项目。

当前交接以包根目录的 `README_交接说明.md`、桌面端源码目录的 `README.md`、运行版的 `使用说明_重要.txt` 和 `开源许可说明.txt` 为准。

新增设计资料：

- `window_pet_cockpit_console_plan.md`：Window Pet Cockpit 控制台设计与接入方案。
- `cockpit_console_mockup.html`：Cockpit 风格控制台静态原型，可直接用浏览器打开预览。
- `third_party_sources.md`：第三方视觉/动作参考来源，当前记录 OpenWhip 鞭子工具的 MIT 许可边界。
